# Contributing to HoangTuoi Reup

1. Fork and clone the repository.
2. Install Node and Python 3.11 dependencies:
   ```powershell
   npm install
   pip install -r backend/requirements.txt
   ```
3. Run tests before opening a Pull Request:
   ```powershell
   npm run test:backend
   npm run typecheck
   npm run build
   ```
4. Never commit proprietary binaries, `.asar` archives, `.pyc` files, credentials, or user data.
